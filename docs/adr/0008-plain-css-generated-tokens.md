# 0008. Plain CSS и токены, сгенерированные из дизайн-системы

- Статус: Принято; шрифт уточнён в 0011, контрольные точки — в 0012
- Дата: 2026-10-27

## Контекст

Дизайн-система MILVIV написана на чистом CSS (`bundle.css`, префикс `.mv-`) поверх CSS-переменных из `tokens.json`. Нужно перенести её в Vue так, чтобы значения не расходились с источником годами, а стили компонентов не протекали друг в друга. Альтернатива — Tailwind v4 (токены через `@theme`, утилиты в шаблонах).

## Решение

- **Plain CSS**: стиль компонента — в `<style scoped>`, глобально только reset, токены, типографика (`shared/styles`). Без Tailwind.
- Копия `tokens.json` лежит в `design/tokens.json`; `scripts/build-tokens.mjs` собирает из неё `src/shared/styles/tokens.css` (`pnpm tokens`). Руками `tokens.css` не правится; CI проверяет, что файл совпадает с источником (`pnpm tokens:check`).
- Стиль текста — шорткат: `font: var(--font-h2); letter-spacing: var(--tracking-h2)`.
- Иконки Lucide — `unplugin-icons` (`~icons/lucide/<name>`, класс `icon`); размер и обводку задают переменные `--icon-size` и `--icon-stroke`, которые компонент выставляет у себя.
- Шрифт Manrope — self-hosted `@fontsource-variable/manrope`: работает без сети (PWA) и без запросов к Google.

## Последствия

- Перенос компонентов из дизайн-системы почти механический: те же свойства, те же токены.
- Обновить токены = заменить `design/tokens.json` и выполнить `pnpm tokens`. Забыть нельзя — упадёт CI.
- Общий вид полей вынесен в `shared/ui/field/control.css` и подключается в каждое поле через `<style scoped src>`: исходник один, scoped-копия у каждого компонента (несколько сотен байт дублирования).
- Контрольные точки нельзя использовать в `@media` как переменные — значения (`767px`, `1024px`) повторяются в медиазапросах.
