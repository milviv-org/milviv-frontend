# 0002. TanStack Query для серверных данных, Pinia — для клиентских

- Статус: Принято
- Дата: 2026-10-20

## Контекст

Почти все данные приложения живут на сервере. Им нужны кеш, дедупликация запросов, отмена, фоновое обновление и инвалидация после изменений. Если писать это вручную в Pinia, получится много одинакового кода и две копии данных, которые расходятся.

## Решение

`@tanstack/vue-query` хранит всё, что пришло с сервера. Pinia — только клиентское состояние: сессия, тема, пароль скрытых наград. Серверные данные в Pinia не копируются.

## Последствия

- Кеш, загрузка, ошибки и повторы — из библиотеки, не своим кодом.
- Ключи кеша задаются только фабриками `xxxKeys` у каждой сущности.
- Разработчику нужно понимать модель TanStack Query (`staleTime`, `gcTime`, инвалидация).
