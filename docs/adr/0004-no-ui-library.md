# 0004. Без UI-библиотек

- Статус: Принято
- Дата: 2026-10-20

## Контекст

Есть своя дизайн-система (docs/DESIGN.md). Готовые UI-библиотеки навязывают свой вид, тянут лишний вес и усложняют точное следование дизайну.

## Решение

UI-kit (`shared/ui`) пишется самостоятельно по дизайн-системе. Для сложной доступности (dialog, popover, combobox, выбор даты) допускаются headless-примитивы без стилей, например Reka UI, — но только по отдельному согласованию перед этапом, где они нужны.

## Последствия

- Полный контроль над видом и размером бандла.
- Больше своего кода, а значит обязательные тесты на доступность (клавиатура, фокус, ARIA).
