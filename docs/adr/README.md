# Architecture Decision Records

Одно архитектурное решение — один файл. ADR отвечает на вопрос «почему так сделано», когда контекст уже забыт. Принятые ADR не переписываются: если решение меняется, пишется новый ADR со статусом «Заменяет NNNN», а у старого статус меняется на «Заменён NNNN».
