# 0007. Явные импорты без auto-import

- Статус: Принято
- Дата: 2026-10-20

## Контекст

Плагины auto-import (`unplugin-auto-import`, `unplugin-vue-components`) экономят строки импортов, но скрывают зависимости: по файлу не видно, откуда пришёл компонент или функция, и линтер границ слоёв (0001) их не видит.

## Решение

Все компоненты, композаблы и API Vue импортируются явно. Линтер ловит неимпортированный компонент (`vue/no-undef-components`).

## Последствия

Каждая зависимость файла видна в его начале и проверяется правилами FSD. Цена — несколько строк импорта.
