# 0012. Контрольные точки — один источник, именованные медиазапросы

- Статус: Принято
- Дата: 2026-10-27
- Уточняет: 0008 (в части контрольных точек)

## Контекст

Контрольные точки (`bp-*` в `tokens.json`: 768, 1024, 1440) были записаны в девяти местах: ручная копия в `shared/config/breakpoints.ts` и числа в медиазапросах восьми файлов, местами производные (`767px`). CSS-переменные в `@media` не работают, поэтому ADR 0008 смирился с повтором. Сдвиг точки в дизайн-системе молча разошёлся бы с кодом — нарушение DRY, которое ничто не проверяло.

## Решение

- Единственный источник — `design/tokens.json`. Генератор (`pnpm tokens`) создаёт из него:
  - `src/shared/styles/media.css` — `@custom-media --mv-mobile`, `--mv-tablet`, `--mv-tablet-up`, `--mv-desktop`, `--mv-desktop-up`, `--mv-wide`;
  - `src/shared/config/media-queries.ts` — `Breakpoint` (числа) и `MediaQuery` (те же строки запросов) для JS.
    CSS и JS получают запросы из одной функции (`scripts/lib/media-queries.mjs`) — строки совпадают.
- Компоненты пишут `@media (--mv-desktop-up)` и подключают `@import '@/shared/styles/media.css'` в каждом блоке стилей, где есть `--mv-*`. Файл даёт 0 байт на выходе.
- Vite обрабатывает CSS через Lightning CSS (`css.transformer: 'lightningcss'`, `drafts.customMedia`): именованные запросы заменяются настоящими при сборке и в dev.
- Синтаксис диапазонов (`width < 768px`) вместо `max-width: 767px` — без производных чисел.
- `pnpm css:check` запрещает числа в медиазапросах по размеру и `--mv-*` без `@import`: Lightning CSS не знает неопределённое имя и молча оставляет запрос нерабочим.

## Последствия

- Сдвинуть точку = поменять `design/tokens.json` и выполнить `pnpm tokens`; CI проверяет, что сгенерированные файлы свежие.
- Плюс одна строка `@import` в блоке стилей с медиазапросами — цена за то, что определения видны только внутри своего файла.
- `@custom-media` — черновик стандарта; когда браузеры его поддержат, сборочный шаг можно будет убрать, синтаксис в компонентах останется.
- Lightning CSS — зависимость Vite, новых пакетов не добавлено.
