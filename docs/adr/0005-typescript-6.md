# 0005. TypeScript 6, а не 7

- Статус: Принято
- Дата: 2026-10-20

## Контекст

На момент старта вышел TypeScript 7 (нативный компилятор). `typescript-eslint` 8.x поддерживает только TypeScript `>=4.8.4 <6.1.0`, а без него не работают правила линтера с типами.

## Решение

`typescript: ~6.0.x`. Обновление — только patch-версии.

## Последствия

Пересмотреть, когда `typescript-eslint` и `vue-tsc` официально поддержат TypeScript 7: проверить их `peerDependencies` и changelog, затем написать ADR «Заменяет 0005».
