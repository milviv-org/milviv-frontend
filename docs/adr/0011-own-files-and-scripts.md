# 0011. Шрифт файлами и свои скрипты проверок вместо пакетов

- Статус: Принято
- Дата: 2026-10-27
- Уточняет: 0008 (в части шрифта)

## Контекст

На этапе 1 шрифт подключался пакетом `@fontsource-variable/manrope`, бюджет бандла проверял `size-limit`. Обе задачи узкие: пакет даёт два woff2-файла и CSS, `size-limit` — одно сравнение с порогом. Каждая зависимость — обновления, риски цепочки поставок и знание чужого API.

## Решение

- Manrope (variable, OFL) — два файла в `src/shared/styles/fonts`: кириллица и латиница. Интерфейс только на русском, остальные подмножества не нужны. `@font-face` — в `fonts.css`, семейство `Manrope` — то же имя, что в токенах дизайн-системы. Лицензия — `fonts/OFL.txt`.
- `scripts/check-bundle-size.mjs` — gzip начальных JS и CSS из `dist/index.html` против бюджета. Превышение — **предупреждение** (в GitHub Actions — аннотация `::warning`), сборку не роняет: решение о росте принимает человек.
- `scripts/check-css-classes.mjs` — проверка префикса `mv-` у классов в стилях (CONVENTIONS, 6.2). Нарушение — ошибка.
- Логика скриптов — чистые функции в `scripts/lib` с unit-тестами.

## Последствия

- Минус три пакета. Обновить шрифт — заменить два файла.
- Проверка размера не блокирует слияние; следить за предупреждениями в CI.
- Если правил для CSS станет больше одного-двух — вернуться к `stylelint`.
