# 0003. Собственный HTTP-клиент на fetch

- Статус: Принято
- Дата: 2026-10-20

## Контекст

Сессия держится на HttpOnly-cookie. По `401` нужно обновить токен и повторить запрос. При этом API запрещает параллельный `/auth/refresh`, даже из разных вкладок: сервер сочтёт токен украденным и завершит сессию.

## Решение

Свой тонкий клиент на `fetch` (`shared/api`): единый `ApiError` с `errorCode`, отмена через `AbortSignal`, общий для вкладки refresh (параллельные `401` ждут один промис) и блокировка между вкладками через Web Locks API.

## Последствия

- Никакой лишней зависимости вроде axios, которая этих задач всё равно не решает.
- Логика refresh — наша ответственность: она изолирована в одном модуле и обязательно покрыта тестами.
