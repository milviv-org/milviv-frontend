# Библиотеки

Каждая зависимость из `package.json`: зачем она, почему она, а не альтернатива, чего стоит и когда её пересмотреть. Новый пакет добавляется сюда в том же коммите ([CONVENTIONS.md](CONVENTIONS.md), раздел 8).

Размеры — gzip в production-бандле, только то, что реально импортируется.

## Рантайм (попадают в бандл)

| Пакет          | Зачем                                                                                                             | Почему он                                                                                                                                                                                       | Цена                                                                          | Пересмотреть, когда                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `vue`          | Фреймворк UI                                                                                                      | Базовый стек (ARCHITECTURE, решение 1)                                                                                                                                                          | ~35 КБ вместе с роутером и Pinia                                              | —                                                                                            |

| `pinia`        | Клиентское состояние: сессия, тема                                                                                | Официальный store Vue; серверные данные — не здесь (ADR 0002)                                                                                                                                   | входит в строку выше                                                          | —                                                                                            |
| `reka-ui`      | Доступные интерактивные примитивы: dialog, drawer, menu, tooltip, select, tabs, checkbox, switch, radio, progress | Headless: вид полностью наш, а клавиатура, фокус, ARIA, позиционирование у края экрана и свайп drawer — проверены сообществом и не требуют нашего кода и тестов. Наследник Radix Vue (ADR 0010) | 10–25 КБ в зависимости от набора; подключаются только используемые компоненты | Ломающий мажор, или проект перестанет поддерживаться. ## Свои скрипты вместо пакетов

| Скрипт                          | Заменяет              | Почему своё                                                                                                             |
| ------------------------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `scripts/build-tokens.mjs`      | Style Dictionary      | Токенов один файл и один формат вывода — генератор на ~80 строк проще настройки библиотеки                              |
| `scripts/check-bundle-size.mjs` | `size-limit`          | Нужна одна проверка: gzip начальных файлов из `index.html` против бюджета, с предупреждением, а не ошибкой              |
| `scripts/check-styles.mjs`      | `stylelint` + плагины | Три правила: префикс `mv-` у классов, нет чисел в медиазапросах, `--mv-*` только с `@import media.css` (CONVENTIONS, 6) |
| `scripts/check-commit-msg.mjs`  | `commitlint`          | Одно регулярное выражение                                                                                               |
