# Бриф для Claude Design: экраны MILVIV

Как использовать: создайте в Claude дизайн (тип Design) и отправьте **Сообщение 1**. Когда он закончит, отправляйте **Сообщения 2–5** по очереди. Одним сообщением всё не влезет хорошо: каждый блок экранов заслуживает внимания.

Текст сообщений составлен по REST API бэкенда. Каждое поле и действие на экранах существует в API, а то, чего в API нет, явно запрещено.

## Сообщение 1 — контекст, правила, авторизация и каркас

```
Нарисуй дизайн всех экранов веб-приложения MILVIV. Используй мою дизайн-систему MILVIV: https://claude.ai/artifact/RxEfsPVxaAjU2ETFeLtEnZ — строго её токены, компоненты, иконки (Lucide), шрифт Manrope, правила акцента, цветов сложности, анимаций и тона текста. Не придумывай новых цветов, радиусов, теней и компонентов: если чего-то не хватает, собери из существующих и отметь это отдельно.

Я буду присылать экраны блоками. Этот блок — контекст, общие правила, авторизация и каркас приложения.

# О продукте
MILVIV — личная система управления целями, проектами и задачами с геймификацией. Один пользователь работает со своими данными; совместной работы, команд и шаринга нет.
Основной цикл: Цель → Проект → Задача → План (когда делать) → Выполнение → Рефлексия (ответы на вопросы) → Баллы → Награда.

Сущности:
- Цель: название, описание. Статуса и срока у цели НЕТ. Прогресс цели вычисляется из её задач (напрямую и через её проекты).
- Проект: название, описание, срок (необязательный), цель (необязательная), статус: активен / завершён / отменён. Сложность проекта пользователь не задаёт — она вычисляется из задач (средний уровень), если задач нет — сложности нет. За проект баллы не начисляются.
- Задача: название, описание, сложность (6 уровней), баллы (по умолчанию по сложности, можно задать своё 1–1000), дата начала, срок, время напоминания, проект и цель (оба необязательны и независимы), статус: активна / выполнена / отменена, признак «просрочена» (активна и срок прошёл).
- Уровни сложности и баллы по умолчанию: Новичок 2, Ученик 3, Адепт 5, Эксперт 8, Мастер 10, Легендарный 20.
- План: когда делать. Разовый (конкретная дата) или повторяющийся (дни недели, например «ср и пт»), всегда с временем «с–до», название, описание, необязательно привязан к задаче.
- Рефлексия: после выполнения задачи пользователь отвечает на вопросы («Что помогло?», «Что помешало?», «Что можно было сделать иначе?» — стандартные, плюс свои).
- Награда: название, описание, стоимость в баллах (1–1 000 000), может быть скрытой (защищена общим паролем). Получить награду = списать её стоимость с баланса; награда остаётся, её можно получать снова.
- Баллы: баланс и история начислений (+ за задачи) и списаний (− за награды).

# Жёсткие правила — чего в приложении НЕТ (не рисуй)
- Нет «Забыли пароль?», восстановления пароля, входа через Google/соцсети, подтверждения email.
- Нет редактирования профиля, аватаров, смены пароля аккаунта, удаления аккаунта. Имя и email только показываются.
- Нет глобального поиска, тегов, приоритетов, подзадач, комментариев, вложений, исполнителей, команд.
- Нет «вернуть в работу» / снять галочку у выполненной задачи: выполнение необратимо. Отменить можно только активную задачу.
- Нет номеров страниц и общего количества элементов в списках («показано 20 из 134») — списки догружаются кнопкой «Показать ещё» или при прокрутке.
- Нет центра уведомлений.
- Нет статуса и срока у целей.

# Общие требования к каждому экрану
- Два размера: десктоп 1440 и мобильный 375. Раскладки — по разделу «Адаптивность» дизайн-системы (Sidebar на десктопе, TabBar снизу на мобильном).
- Основная тема — светлая; для экранов Сегодня, Задачи, Награды, Ассистент дополнительно покажи тёмную.
- Для списков покажи три состояния: с данными, пустое состояние (объясняет и даёт один шаг), загрузка (скелетоны той же формы).
- Создание и редактирование открываются поверх страницы: модалка на десктопе, Drawer снизу на мобильном.
- Удаление — всегда через ConfirmDialog с понятным последствием («Задачи проекта останутся, но без проекта»).
- Используй реалистичные данные на русском: цель «Выучить английский», проекты «Грамматика», «Разговорная практика», задачи «Выучить времена Simple» (Эксперт, 8), «Прочитать статью BBC» (Ученик, 3), «Сдать пробный IELTS» (Легендарный, 20), награды «Новая игра — 5 000», «Поход в кино — 800».

# Экраны этого блока

1. Вход. Поля: email, пароль. Кнопка «Войти», ссылка «Создать аккаунт». Ошибки: «Неверный email или пароль» (одинаковая для любой причины), «Слишком много попыток, попробуйте через 15 минут». Состояние загрузки кнопки. На экране — название MILVIV шрифтом (.mv-wordmark) и одна строка о продукте. Без иллюстраций.

2. Регистрация. Поля: имя (до 100 символов), email, пароль (8–64 символа, подсказка под полем). Кнопка «Создать аккаунт», ссылка «Уже есть аккаунт? Войти». Ошибки под полями, «Этот email уже зарегистрирован». После регистрации пользователь сразу входит.

3. Каркас приложения.
   - Десктоп: Sidebar с разделами Сегодня, Задачи, Проекты, Цели, Календарь, Награды, Статистика, Ассистент, Настройки; внизу Sidebar — имя пользователя и выход. Баланс баллов (PointsCounter с иконкой gem) всегда виден — в Sidebar или шапке.
   - Мобильный: TabBar — Сегодня, Задачи, Календарь, Награды, Ещё. «Ещё» открывает Drawer с остальными разделами, именем пользователя и выходом. Баланс — в шапке экрана.
   - Глобальная кнопка «Создать задачу» (самое частое действие) — придумай её место в рамках дизайн-системы для обеих ширин.

4. Системные экраны и состояния:
   - 404 «Страница не найдена» со ссылкой на «Сегодня».
   - Общая ошибка «Что-то пошло не так» с кнопкой «Обновить».
   - Сессия истекла (toast + переход на вход).
   - Нет сети (ненавязчивая полоса сверху).
   - Конфликт версий: диалог «Данные изменились, пока вы редактировали. Обновить и потерять свои правки / Остаться» — возникает при сохранении, если объект изменили в другой вкладке.
   - Примеры toast: успех, ошибка, «Слишком много запросов, попробуйте позже».

## Сообщение 2 — Сегодня, задачи, проекты, цели

```
Следующий блок: Сегодня, Задачи, Проекты, Цели. Те же правила, что в первом сообщении.

5. Сегодня (главная). Данные дня:
   - планы на сегодня по времени (разовые и повторяющиеся, время «19:00–20:00», название, связанная задача если есть, иконка repeat у повторяющихся);
   - задачи со сроком сегодня;
   - просроченные активные задачи (отдельной группой, мягко, без паники);
   - выполненные сегодня задачи (приглушённые, с полученными баллами);
   - проекты со сроком сегодня.
   Заголовок с датой («чт, 22 октября»), баланс баллов. Покажи поощрение TaskReward прямо в списке. Пустое состояние «На сегодня ничего не запланировано».

6. Список задач.
   - Вкладки статуса: Активные / Выполненные / Отменённые / Все.
   - Фильтры: проект, цель (выбор из списка). Других фильтров и сортировок нет; список — новые первыми.
   - TaskCard: чекбокс выполнения (только у активных), название, бейдж сложности, баллы, срок (просроченный выделен по правилам дизайн-системы), проект/цель мелко. Меню карточки: Изменить, Отменить задачу, Удалить.
   - «Показать ещё» внизу.

7. Деталь задачи (своя страница с URL).
   - Всё о задаче: название, описание, сложность и баллы, статус, даты начала и срока, напоминание, проект и цель (ссылками), когда выполнена.
   - Действия: Выполнить, Отменить (только у активной), Изменить, Удалить. У выполненной — только Изменить и Удалить (баллы при этом сохраняются — скажи это в ConfirmDialog удаления).
   - Блок «Планы задачи»: список планов + «Запланировать».
   - Блок «Рефлексия»: вопросы задачи (набор можно изменить: выбрать из стандартных и своих, или отключить рефлексию совсем); у выполненной — ответы; на неотвеченные можно ответить. Ответ даётся один раз и не редактируется.

8. Форма задачи (создание и редактирование).
   - Название (обязательно), описание.
   - Сложность — выбор из 6 уровней, у каждого видны цвет, ступени и баллы по умолчанию.
   - Баллы: по умолчанию подставляются по сложности; можно задать своё (1–1000) — продумай, как показать «своё значение» и как вернуть к значению по сложности.
   - Дата начала, срок (не раньше начала; если выбран проект со сроком — не позже срока проекта, покажи эту ошибку).
   - Напоминание: дата и время.
   - Проект, цель — необязательные выпадающие списки.

9. Выполнение задачи и рефлексия. После выполнения — поощрение TaskReward. Затем ненавязчивое предложение ответить на вопросы рефлексии (не модалка, блокирующая работу): можно ответить сейчас, на часть вопросов, или позже со страницы задачи. Если у задачи рефлексия отключена — предложения нет.

10. Список проектов. Вкладки: Активные / Завершённые / Отменённые / Все; фильтр по цели. Карточка: название, цель, срок, вычисленная сложность (бейдж или «Нет задач»), прогресс (ProgressBar: % выполненных среди неотменённых; число активных, выполненных, просроченных; заработанные баллы).

11. Деталь проекта. Описание, цель, срок, сложность, прогресс; список задач проекта (с теми же вкладками статуса) и «Добавить задачу» (форма задачи с предвыбранным проектом). Действия: Завершить проект, Отменить проект (оба не меняют задачи — скажи это в подтверждении), Изменить, Удалить («Задачи останутся без проекта»).
    Форма проекта: название, описание, срок (не раньше самого позднего срока его задач — ошибка «Сначала перенесите сроки задач»), цель.

12. Список целей. Карточки GoalCard (2–3 колонки на десктопе): название, описание кратко, количество проектов, прогресс (как у проекта), заработанные баллы. Статуса у целей нет.

13. Деталь цели. Описание, прогресс; проекты цели (карточки); задачи, привязанные к цели напрямую; кнопки «Добавить проект», «Добавить задачу». Удаление: «Проекты и задачи цели останутся, но без цели».
    Форма цели: название, описание.
```

## Сообщение 3 — календарь, награды, статистика

```
Следующий блок: Календарь, Награды и баллы, Статистика. Те же правила.

14. Календарь — вид «Месяц». Сетка месяца, в каждом дне компактно: количество планов, точки сроков задач (цвет сложности), отметка выполненных, сроки проектов (иконка flag). Навигация по месяцам, «Сегодня». Клик по дню — панель дня (справа на десктопе, Drawer на мобильном) с четырьмя группами: Планы (по времени), Сроки задач, Выполнено, Сроки проектов.

15. Календарь — вид «Неделя». Колонки дней, шкала времени, планы — блоки «с–до»; над шкалой — сроки задач и проектов дня, выполненные задачи. На мобильном — продумай удобный вид недели (например, один день с переключением). Переключатель Месяц / Неделя.

16. Форма плана.
   - Название (обязательно), описание.
   - Тип: «Разово» (выбор даты) или «Повторять» (выбор дней недели Пн–Вс, можно несколько).
   - Время с / до (обязательно, конец позже начала).
   - Связанная задача — необязательный выбор.
   Повторяющийся план действует со дня создания.

17. Награды.
   - Вверху — баланс крупно (numeric-lg).
   - Список наград (от дешёвых к дорогим): название, описание, стоимость, прогресс накопления (баланс / стоимость), кнопка «Получить» (неактивна, если баллов не хватает — покажи, сколько осталось). Получение — подтверждение, затем поощрение RewardRedeem, баланс досчитывает вниз.
   - Меню награды: Изменить, Удалить.
   - Скрытые награды: свёрнутый блок «Скрытые награды» с замком. Чтобы открыть — ввести пароль скрытых наград. После ввода скрытые видны вместе с обычными (с иконкой-замком) и снова закрываются автоматически через некоторое время и при уходе со страницы. Ошибки: неверный пароль; «Слишком много попыток, попробуйте позже».
   - Если пароль скрытых наград ещё не задан — вместо ввода предложение задать (ведёт в Настройки).

18. Форма награды: название, описание, стоимость (1–1 000 000), переключатель «Скрытая» (доступен, только если скрытые награды сейчас открыты паролем; иначе — подсказка почему).

19. История баллов (вкладка или блок на странице Наград): лента записей «+8 · Задача выполнена: Выучить времена Simple» / «−5 000 · Награда: Новая игра», дата и время; ссылка на задачу или награду, если они не удалены. Запись о скрытой награде без пароля показывается как «Получена скрытая награда» без названия. «Показать ещё».

20. Статистика.
   - Выбор периода: неделя, месяц, свой период (не длиннее года).
   - Сводка: выполнено задач, заработано баллов.
   - График по дням (выполнено, баллы) за период.
   - По сложности: все 6 уровней, включая нулевые (количество и баллы) — цвета сложностей.
   - Сроки: вовремя / с опозданием / без срока.
   - План против факта: в плановый день / раньше / позже / без плана.
   - Переносы: сколько раз переносили плановую дату и сколько разных задач.
   - По дням недели: Пн–Вс.
   - Прогресс проектов: список с ProgressBar (фильтр по статусу).
   - Прогресс целей: список с ProgressBar и числом проектов.
   Графики — минималистичные (столбцы, кольцо), из токенов дизайн-системы, без 3D и лишних сеток. Покажи пустое состояние «За этот период нет выполненных задач».
```

## Сообщение 4 — AI-ассистент

```
Следующий блок: AI-ассистент — отдельная страница. Те же правила. Здесь много состояний, нарисуй каждое.

Как он работает (важно для дизайна):
- Пользователь пишет обычной фразой, что хочет: «Хочу выучить английский», «Перенеси задачи по грамматике на неделю», «Какие задачи я чаще всего просрочиваю?».
- ИИ отвечает текстом и/или выполняет операции с целями, проектами, задачами и наградами.
- ИСТОРИИ ДИАЛОГА НЕТ: каждый запрос самостоятельный, ИИ не помнит предыдущие сообщения. Поэтому не рисуй классический чат с перепиской — лучше лента карточек «запрос → результат». Дизайн не должен создавать ощущения, что ИИ помнит разговор.
- Одновременно обрабатывается только один запрос; ответ может идти до 90 секунд.
- Создание ИИ выполняет сразу; каждое изменение и удаление пользователь подтверждает галочкой; неподтверждённое отменяется.
- ИИ НЕ умеет: отмечать задачи выполненными или отменять их, получать награды, видеть скрытые награды, менять планы и ответы рефлексии.

21. Окно согласия (при первом входе на страницу, до согласия ассистент недоступен). Текст должен сказать: ИИ читает ваши цели, проекты, задачи, награды (кроме скрытых), планы, ответы рефлексии и память ИИ; данные передаются Google Gemini; используется бесплатный тариф, поэтому Google может использовать данные по своим условиям. Согласие даётся один раз и не отзывается. Кнопки «Согласен» / «Не согласен». Состояние страницы после «Не согласен».

22. Ввод запроса: поле до 2000 символов со счётчиком, кнопка отправки; подсказки-примеры для пустой страницы. Состояние ожидания (до 90 с) — спокойный индикатор, поле заблокировано.

23. Карточка результата — по одному макету на каждый статус:
   - Ответ: текст ответа.
   - Выполнено: краткое резюме + блок «Отчёт» — список созданных / изменённых / удалённых / отменённых целей, проектов, задач и наград (иконка типа, название, ссылка; у удалённых ссылки нет). Деталей «было → стало» в отчёте нет.
   - Ждёт подтверждения: резюме (что ИИ предлагает и зачем), отчёт уже созданного, затем карточка подтверждения — список предложенных изменений и удалений (операция «Изменить» / «Удалить», тип, название) с ПУСТЫМИ галочками по умолчанию; кнопки «Выполнить отмеченные» и «Отклонить все»; срок, до которого можно решить (24 часа). Подтверждённое выполняется всё вместе или ничего.
   - Отклонено: отчёт (созданное осталось — скажи это).
   - Истекло: «Предложение устарело, изменения не выполнены».
   - Нужно уточнение: вопрос ИИ + кнопка «Дополнить запрос», которая подставляет исходный текст в поле ввода для правки (истории нет).
   - Ошибки: ИИ отказался (с причиной, «переформулируйте»); лимит запросов исчерпан («попробуйте через N мин» с обратным отсчётом); ИИ временно недоступен; не ответил вовремя; данные изменились, пока ИИ думал — «отправьте запрос снова»; слишком большой план — «сузьте запрос».
   - В каждой карточке сворачиваемый блок «Что смотрел ИИ»: список «Задачи — 12 шт. — Найти просроченные задачи», «Память — 2 записи».
   - Действие «Сохранить вывод в память» у ответа.

24. История запросов: лента прошлых карточек, новые сверху, «Показать ещё».

25. Память ИИ (панель или вкладка): список выводов пользователя («Мне проще выполнять сложные задачи вечером»), максимум 20 записей по 500 символов; добавить, удалить (редактирования нет — удалить и сохранить заново); состояние «Память заполнена».
```

## Сообщение 5 — настройки

```
Последний блок: Настройки. Те же правила. Разделы — вкладки (на мобильном список разделов → экран раздела).

26. Внешний вид: тема — Светлая / Тёмная / Как в системе.

27. Звуки. Общий переключатель «Звуки» (выключает все). Пять событий: Задача создана, Задача выполнена, Задача отменена, Напоминание, Задача просрочена. Для каждого — выбор звука из встроенного каталога с кнопкой прослушивания и «По умолчанию».

28. Уведомления: включить напоминания о задачах (браузер спросит разрешение); пояснение, что напоминания приходят, пока приложение открыто; состояние «Уведомления запрещены в браузере».

29. Рефлексия: стандартные вопросы (только просмотр, с меткой «Стандартный»); свои вопросы — добавить, изменить, удалить (до 100, текст до 500 символов). Подсказка: новым задачам назначаются стандартные вопросы; ответы на удалённые вопросы сохраняются.

30. Скрытые награды: задать или сменить пароль скрытых наград (4–64 символа). Подтверждается паролем аккаунта — так же восстанавливается забытый пароль скрытых наград. Ошибки: неверный пароль аккаунта; слишком много попыток.

31. Аккаунт: имя и email (только просмотр), кнопка «Выйти».

В конце пришли список того, что пришлось собрать из существующих компонентов или чего не хватило в дизайн-системе.
