Как использовать: создайте в Claude дизайн (тип Design, дизайн-система MILVIV) и отправьте **Сообщение 0** — контекст и правила, без экранов. Затем отправляйте по одному сообщению на страницу, дожидаясь результата каждого.

## Сообщение 0 — контекст и правила

```
Нарисуй дизайн всех экранов веб-приложения MILVIV. Используй мою дизайн-систему MILVIV: https://claude.ai/artifact/RxEfsPVxaAjU2ETFeLtEnZ — строго её токены, компоненты, иконки (Lucide), шрифт Manrope, правила акцента, цветов сложности, анимаций и тона текста. Не придумывай новых цветов, радиусов, теней и компонентов: если чего-то не хватает, собери из существующих и отметь это отдельно.

Экраны я буду присылать по одному сообщению. В этом сообщении — только контекст и правила, которые действуют для ВСЕХ следующих экранов. Пока ничего не рисуй: коротко подтверди, что понял, и жди первый экран.

# О продукте
MILVIV — личная система управления целями, проектами и задачами с геймификацией. Один пользователь работает со своими данными; совместной работы, команд и шаринга нет.
Основной цикл: Цель → Проект → Задача → План (когда делать) → Выполнение → Рефлексия (ответы на вопросы) → Баллы → Награда.

Сущности:
- Цель: название, описание. Статуса и срока у цели НЕТ. Прогресс цели вычисляется из её задач (напрямую и через её проекты).
- Проект: название, описание, срок (необязательный), цель (необязательная), статус: активен / завершён / отменён. Сложность проекта пользователь не задаёт — она вычисляется из задач (средний уровень), если задач нет — сложности нет. За проект баллы не начисляются.
- Задача: название, описание, сложность (6 уровней), баллы (по умолчанию по сложности, можно задать своё 1–1000), дата начала, срок, время напоминания, проект и цель (оба необязательны и независимы), статус: активна / выполнена / отменена, признак «просрочена» (активна и срок прошёл).
- Уровни сложности и баллы по умолчанию: Новичок 2, Ученик 3, Адепт 5, Эксперт 8, Мастер 10, Легендарный 20.
- План: когда делать. Разовый (конкретная дата) или повторяющийся (дни недели, например «ср и пт»), всегда с временем «с–до», название, описание, необязательно привязан к задаче.
- Рефлексия: после выполнения задачи пользователь отвечает на вопросы («Что помогло?», «Что помешало?», «Что можно было сделать иначе?» — стандартные, плюс свои).
- Награда: название, описание, стоимость в баллах (1–1 000 000), может быть скрытой (защищена общим паролем). Получить награду = списать её стоимость с баланса; награда остаётся, её можно получать снова.
- Баллы: баланс и история начислений (+ за задачи) и списаний (− за награды).

# Жёсткие правила — чего в приложении НЕТ (не рисуй)
- Нет «Забыли пароль?», восстановления пароля, входа через Google/соцсети, подтверждения email.
- Нет редактирования профиля, аватаров, смены пароля аккаунта, удаления аккаунта. Имя и email только показываются.
- Нет глобального поиска (есть только поиск в списке задач по названию и описанию), тегов, приоритетов, подзадач, комментариев, вложений, исполнителей, команд.
- Нет «вернуть в работу» / снять галочку у выполненной задачи: выполнение необратимо. Отменить можно только активную задачу.
- Списки разбиты на страницы с нумерацией (компонент Pagination): «‹ 1 2 3 … 12 ›» на десктопе, компактно «‹ 3 из 12 ›» на мобильном; рядом — «Показано 51–100 из 134». Номер страницы хранится в адресе. Размер страницы: карточки (цели, проекты) — 12, строчные списки — 20. Если всё помещается на одну страницу, пагинации нет. Бесконечной прокрутки и «Показать ещё» нет.
- Нет центра уведомлений.
- Нет статуса и срока у целей.
- Нет времени у срока задачи и срока проекта — это только даты («до 22 окт», «сегодня», «просрочено на 3 дня»). Время есть только у напоминания задачи и у планов («19:00–20:00»).

# Общие требования к каждому экрану
- Два размера: десктоп 1440 и мобильный 375. Раскладки — по разделу «Адаптивность» дизайн-системы (Sidebar на десктопе, TabBar снизу на мобильном).
- Основная тема — светлая; для экранов Сегодня, Задачи, Награды, Ассистент дополнительно покажи тёмную.
- Для списков покажи три состояния: с данными, пустое состояние (объясняет и даёт один шаг), загрузка (скелетоны той же формы).
- Primary: глобальная «Создать задачу» (Sidebar, плавающая кнопка) — часть каркаса и в счёт не входит; в области контента — не больше одной primary, главное действие страницы («Выполнить», «Сохранить ответы», «Обновить» на странице ошибки).
- Кнопка в пустом состоянии — всегда secondary: она дублирует контекстное создание в заголовке и на мобильном соседствует с плавающей кнопкой.
- Шапка на мобильном: слева «Назад» (на детальных страницах), справа баланс. Название страницы — отдельной строкой под шапкой, справа в этой строке — контекстное действие.
- Создание и редактирование открываются поверх страницы: модалка на десктопе, Drawer снизу на мобильном.
- Удаление — всегда через ConfirmDialog с понятным последствием.
- Контекстное создание («Создать проект», «Создать цель», «Создать награду») — в строке заголовка страницы справа; на мобильном — иконка с aria-label. Общую шапку с балансом не трогаем; глобальная «Создать задачу» — отдельно.
- На мобильном разделы из меню «Ещё» (Проекты, Цели, Статистика, Ассистент, Настройки) и их детальные страницы подсвечивают в TabBar «Ещё»; у детальных страниц — «Назад» в заголовке.
- Используй реалистичные данные на русском: цель «Выучить английский», проекты «Грамматика», «Разговорная практика», задачи «Выучить времена Simple» (Эксперт, 8), «Прочитать статью BBC» (Ученик, 3), «Сдать пробный IELTS» (Легендарный, 20), награды «Новая игра — 5 000», «Поход в кино — 800».
```

## Сообщение 7 — Деталь задачи

```
Экран 7. Деталь задачи — отдельная страница со своим адресом.
- Всё о задаче: название, описание, сложность и баллы, статус, дата начала и срок, напоминание, проект и цель (ссылками), когда выполнена.
- Действия активной задачи: Выполнить, Отменить, Изменить, Удалить.
- У выполненной и отменённой — только Изменить и Удалить. Подтверждение удаления: активной — «Задача и её планы будут удалены»; выполненной — «Задача и её планы будут удалены. Полученные баллы и ответы рефлексии сохранятся».
- Блок «Планы задачи»: список планов задачи. «Запланировать» — только у активной; у выполненной и отменённой существующие планы только для просмотра (удалить можно).
- Блок «Рефлексия»: вопросы задачи; набор можно изменить в любом статусе, в том числе у выполненной (уже данные ответы сохраняются — подскажи это). В редакторе вопросы только выбираются из стандартных и своих, или рефлексия отключается совсем; свои вопросы создаются в Настройках (ссылка). У выполненной — ответы; на неотвеченные можно ответить. Ответ даётся один раз и не редактируется. После «Выполнить» блок сразу переходит в режим ответов.
- Покажи три варианта: активная, выполненная с ответами, отменённая.
```

## Сообщение 8 — Форма задачи

```
Экран 8. Форма задачи — создание и редактирование (модалка на десктопе, Drawer снизу на мобильном).
- Название (обязательно, до 255), описание.
- Сложность — выбор из 6 уровней; у каждого видны цвет, ступени и баллы по умолчанию.
- Баллы: по умолчанию подставляются по сложности; можно задать своё (1–1000). Продумай, как показать «своё значение» и как вернуть значение по сложности.
- Дата начала и срок — только даты, без времени. Ошибки: срок раньше начала; «Срок не может быть позже срока проекта (1 декабря)», если выбран проект со сроком.
- Напоминание: дата и время.
- Проект, цель — необязательные выпадающие списки. В списке проектов — только активные; если задача уже в завершённом или отменённом проекте, он остаётся выбранным значением, но заново его не выбрать.
- У начала, срока, напоминания, проекта и цели — крестик очистки прямо в поле, когда значение задано (у пустого поля его нет).
- Кнопки «Создать задачу» / «Сохранить», «Отмена». Состояние сохранения и ошибки под полями.
```

## Сообщение 9 — Выполнение задачи и рефлексия

```
Экран 9. Выполнение задачи и рефлексия.
- После выполнения — поощрение TaskReward (сила по уровню сложности).
- Затем ненавязчивое предложение ответить на вопросы рефлексии — НЕ блокирующая модалка. Можно ответить сейчас, ответить на часть вопросов или отложить и ответить позже со страницы задачи.
- Предложение раскрывается под выполненной карточкой (везде, где можно выполнить задачу: Сегодня, Задачи, панель дня календаря) — после окончания поощрения, плавно. Открыто только одно: выполнение следующей задачи сворачивает прежнее. Заголовок с числом вопросов задачи («4 вопроса», с согласованием). Действие «Позже» сворачивает блок; после сохранения — короткое «Ответы сохранены» и сворачивание.
- Одна кнопка «Сохранить ответы» на все вопросы: сохраняет только заполненные, пустые остаются на потом. Неактивна, пока ничего не заполнено. Мелкая подсказка «Ответы нельзя будет изменить»; сохранённые ответы показываются текстом, а не полем. Так же — в блоке рефлексии на странице задачи.
- Если у задачи рефлексия отключена — предложения нет.
- Покажи: предложение, заполнение ответов, частично отвеченное, всё отвечено.
```

## Сообщение 11 — Деталь и форма проекта

```
Экран 11. Деталь проекта и форма проекта.
Деталь:
- Описание, цель (ссылкой), срок, вычисленная сложность, прогресс.
- Список задач проекта с теми же вкладками статуса, «Добавить задачу» (открывает форму задачи с предвыбранным проектом).
- Действия: Завершить проект, Отменить проект (оба не меняют задачи — скажи это в подтверждении), Изменить, Удалить («Задачи останутся, но без проекта»).
- У завершённого и отменённого — только Изменить и Удалить (на мобильном — в панели «⋯»). «Вернуть в работу» и «Добавить задачу» нет.
- «Добавить задачу» открывает форму задачи с предвыбранным проектом; цель НЕ подставляется (цель задачи независима от цели проекта) — под полем «Цель» подсказка «Через проект задача уже входит в цель „…“».
- Плавающей «Создать задачу» на детальных страницах (задача, проект, цель) нет; кнопка в Sidebar остаётся.
- Варианты: активный, завершённый.
Форма (модалка / Drawer):
- Название (обязательно), описание, срок, цель.
```

## Сообщение 21 — Ассистент: согласие

```
Экран 21. AI-ассистент — согласие. Ассистент — отдельная страница; следующие четыре экрана тоже про него.

Как работает ассистент (важно для всех его экранов):
- Пользователь пишет обычной фразой, что хочет: «Хочу выучить английский», «Перенеси задачи по грамматике на неделю», «Какие задачи я чаще всего просрочиваю?».

- ИСТОРИИ ДИАЛОГА НЕТ: каждый запрос самостоятельный, ИИ не помнит предыдущие сообщения. Поэтому не рисуй классический чат с перепиской — лучше лента карточек «запрос → результат». Дизайн не должен создавать ощущения, что ИИ помнит разговор.
- Одновременно обрабатывается только один запрос; ответ может идти до 90 секунд.
- Создание ИИ выполняет сразу; каждое изменение и удаление пользователь подтверждает галочкой; неподтверждённое отменяется.
- ИИ НЕ умеет: отмечать задачи выполненными или отменять их, получать награды, видеть скрытые награды, менять планы и ответы рефлексии.

Этот экран — окно согласия при первом входе на страницу (до согласия ассистент недоступен):
- Текст: ИИ читает ваши цели, проекты, задачи, награды (кроме скрытых), планы, ответы рефлексии и память ИИ; данные передаются Google Gemini; используется бесплатный тариф, поэтому Google может использовать данные по своим условиям. Согласие даётся один раз и не отзывается.

- Кнопки «Согласен» / «Не согласен» — одинакового веса (secondary), «Согласен» справа: согласие необратимо, интерфейс не подталкивает к выбору.
```
