# Дизайн: где сделать и что передать в разработку

> **Источник дизайна:** дизайн-система MILVIV в Claude — https://claude.ai/artifact/RxEfsPVxaAjU2ETFeLtEnZ
> **Экраны:** «MILVIV — экраны» — https://claude.ai/artifact/Aj65WhrTAfby3nX11KLQan (по брифу [DESIGN-BRIEF.md](DESIGN-BRIEF.md); перед каждым этапом макеты этапа сверяются с брифом и API).
> Дизайн-система — источник правды для токенов (`tokens.json`), компонентов (`components/*`) и правил анимаций и поощрений. Значения в `src/shared/styles/tokens.css` переносятся оттуда 1:1. Если дизайн-система изменилась, сначала правим её, затем код.

Дизайн готов. Как он переносится в код:

| Из дизайн-системы                | В код                                                                                                                                    |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `project/tokens.json`            | `design/tokens.json` → `pnpm tokens` → `src/shared/styles/tokens.css` (ADR 0008)                                                         |
| `components/bundle.css` (`.mv-`) | `<style scoped>` компонентов `src/shared/ui`, классы — БЭМ `mv-` (CONVENTIONS, 6.2); `is-*` заменены атрибутами состояния                |
| `components/*/README.md`         | Правила использования — в TSDoc компонента и его props                                                                                   |
| Поведение слоёв и контролов      | Reka UI (ADR 0010). Отличие от дизайн-системы: Select — список Reka, а не нативный `<select>` — поправить README Select в дизайн-системе |
| Шрифт Manrope (Google Fonts)     | Два файла в `src/shared/styles/fonts` (ADR 0011)                                                                                         |
| `components/bundle.js`           | Поощрения (досчёт, «+N», частицы) — этапы 6 и 8, в доменных фичах                                                                        |
| Набор иконок (Lucide)            | `~icons/lucide/<name>` через `unplugin-icons`                                                                                            |

Остальная часть документа — история выбора инструментов, сохранена для справки.

## Инструменты с ИИ

| Инструмент                                | Что умеет                                                                       | Когда выбрать                                                                                                              |
| ----------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **Google Stitch** (stitch.withgoogle.com) | Генерирует экраны по текстовому описанию, экспорт в Figma и HTML/CSS. Бесплатно | **Рекомендую для старта**: быстро получить варианты визуального стиля                                                      |
| **Figma** (+ Figma Make / AI-функции)     | Полноценный редактор, компоненты, стили, варианты                               | Финальный дизайн и долгая поддержка. Я могу читать макеты напрямую через Figma MCP-сервер (точные цвета, отступы, размеры) |
| **v0.dev**                                | Генерирует экраны в коде (React + Tailwind)                                     | Как визуальный референс; код не переносим, только смотрим                                                                  |
| **Claude (здесь)**                        | Могу сделать кликабельный HTML-прототип экранов и дизайн-систему                | Если хотите обсуждать вид сразу в коде и правками словами                                                                  |

**Рекомендуемый путь:** Stitch — найти стиль (3–4 варианта главного экрана) → перенести выбранный в Figma и довести → подключить Figma MCP, чтобы я брал значения из макета.

## Что нужно от дизайна (минимум)

1. **Токены**: палитра (фон, поверхности, текст, акцент, успех/предупреждение/ошибка), **6 цветов сложностей**, шрифт и шкала размеров, отступы, радиусы, тени — в светлой и тёмной теме.
2. **Компоненты в состояниях** default / hover / focus / disabled / error: кнопки, поля, select, чекбокс, переключатель, модалка, toast, бейдж сложности, прогресс-бар, карточка задачи.
3. **Экраны** в двух ширинах (мобильный ~375px, десктоп ~1440px): вход, сегодня, список задач, деталь задачи, форма задачи, цели, проект, календарь (месяц и неделя), награды, статистика, ассистент (включая карточку подтверждения), настройки.
4. **Пустые состояния и загрузка**: что видно, когда задач нет, и пока данные грузятся.

## Подсказка для генератора (пример)

> Веб-приложение MILVIV для управления целями, проектами и задачами с геймификацией. Задачи имеют 6 уровней сложности: Новичок, Ученик, Адепт, Эксперт, Мастер, Легендарный — за выполнение начисляются баллы, которые можно обменять на награды. Экран «Сегодня»: планы дня по времени, задачи со сроком сегодня, баланс баллов. Адаптивный, светлая и тёмная тема, русский интерфейс. Стиль: [ваш выбор — минималистичный / фэнтези в духе RPG / …].

Названия уровней совпадают со ступенями навыков из Skyrim. Фэнтези-RPG-стилистика может стать сильной идеей, но это вопрос вашего вкуса.
